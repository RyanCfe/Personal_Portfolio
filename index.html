01 / DATA

Pipeline · API · dashboard

Netflix analytics dashboard

A Netflix CSV became a normalized SQLite database, a FastAPI backend and a Streamlit dashboard. Search titles and explore genres, cast, directors and countries.

The CSV looked simple until one title had several people, genres and countries attached to it. I liked making those relationships usable.

Python / SQLite / FastAPI / StreamlitView code ↗
02 / API

Machine learning · backend

Iris prediction API

A Django REST Framework endpoint that loads a trained scikit-learn model and predicts from JSON. I worked through token authentication, PostgreSQL and migrations, then tested it locally.

Training the model was one step. Getting authentication, the database and the endpoint to work together was the part I learned from.

Python / Django REST / scikit-learn / PostgreSQL
03 / LIVE

Real-time prototype

Socket game playground

A multiplayer playground with rooms and shared boards using Socket.IO. Some game modes are still experiments, but working through shared state was the point.

This made “works on my screen” a pretty useless test. A move has to make sense on yours too.

JavaScript / Node / Express / Socket.IO / Firebase
04 / RISK

Financial analysis

Gold ETF comparison

I compared SBI Gold ETF, HDFC Gold ETF and Nippon Gold BeES over March 2025–March 2026 using cumulative return, annualized volatility and Sharpe ratios in Excel.

Looking at the Sharpe ratio changed how I read the returns. I wanted the risk right beside the number that looked good.

Excel / statistics / risk & return
05 / SYSTEMS

Local infrastructure

Containerized web stack

A FastAPI backend, Next.js frontend, PostgreSQL and Nginx brought together with Docker Compose. It taught me a lot about how services connect and how to debug them.

Putting these services in one stack is what got me asking how I’d run the whole thing beyond my laptop.

FastAPI / Next.js / PostgreSQL / Nginx / Docker
