Selected work

Five projects at different stages, from analysis to working local builds.

01Data pipeline & dashboard

Netflix analytics dashboard

I took a Netflix CSV through a normalized SQLite database, a FastAPI backend and a Streamlit dashboard. The interface lets you search titles and explore genres, actors, directors and countries.

Python · SQLite · FastAPI · Streamlit

View the code ↗
02Machine learning API

Iris prediction API

A Django REST Framework API that loads a trained scikit-learn Iris model and returns a prediction from JSON input. I worked through token authentication, PostgreSQL configuration and migrations, then tested it locally.

Python · Django REST Framework · scikit-learn · PostgreSQL

03Real-time prototype

Socket game playground

I built a multiplayer playground prototype with rooms and shared boards using Socket.IO. It was a chance to work through real-time events and state between players; some game modes are still early experiments.

JavaScript · Node.js · Express · Socket.IO · Firebase Admin

04Financial analysis

Gold ETF comparison

I compared SBI Gold ETF, HDFC Gold ETF and Nippon Gold BeES across March 2025–March 2026. In Excel, I calculated cumulative return, annualized volatility and Sharpe ratios to look at risk alongside return.

Excel · Statistics · Risk and return

05Local infrastructure build

Containerized web stack

I put together a local multi-service setup with a FastAPI backend, Next.js frontend, PostgreSQL and Nginx using Docker Compose. The useful part was learning how the services connect and troubleshooting them when they did not.

FastAPI · Next.js · PostgreSQL · Nginx · Docker Compose
